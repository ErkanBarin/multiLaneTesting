# Support

## Where to ask questions

Use GitHub Issues or GitHub Discussions on this repository:
<https://github.com/ErkanBarin/multiLaneTesting>

- **Bug reports** — open an issue using the bug report template.
- **Feature requests** — open an issue using the feature request template.
- **Questions and general discussion** — open a GitHub Discussion or an issue
  if Discussions are not enabled.

There is no mailing list, chat channel, or forum at this time.

## What to include

To get useful help, please provide:

- The `@multilane/*` package(s) involved
- Your Node version (`node --version`) and OS
- A minimal reproduction or the exact command you ran
- The full error message or unexpected output
- What you expected to happen

Do not paste internal hostnames, credentials, tokens, or secrets into public
issues or discussions.

## Experimental status

This project is pre-1.0 and experimental. Support is best-effort with no
guaranteed response time or SLA. The API and behavior may change without
notice between releases.
